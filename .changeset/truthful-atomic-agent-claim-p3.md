Truthful atomic agent claims on both surfaces. Agent claims now travel through the shared claim operation: the local primitive and its preview select through one eligibility selector (roots-first at the operation level, unfinished blockers and inactive ancestry suppressed, priority-then-created order), and remote mode claims with a single versioned agent-claim request whose selection and write the board owns. A claim never reports success when the remote refuses, an old board is a specific unsupported-version refusal instead of a silent fallback, and `tasks --next --dry-run` previews through the same path without writing.
