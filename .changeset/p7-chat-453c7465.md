Agent-chat page reads behind classified shared operations (ticket 453c7465,
P7 chat increment). New `readPageText` and `readPageDom` operations in
`core/operations/chat.ts` are the registry-bound wrappers for the
chat-only `read_page_text` / `read_page_dom` tools: read-only and
approval-free by classification, never board writes, with no CLI spelling
and no main-manifest MCP tool. The `agent-chat/mcp.ts` dispatch now routes
through them with the raw tool input, session id, and tab hook forwarded
verbatim; the bounded fetch, per-hop SSRF block, caps, untrusted wrapping,
and deterministic DOM refusals stay in the existing runners. No behaviour
change on the wire.
