Parent task concept: tasks can now be linked hierarchically with parent-child relationships. Children group under their parent in the kanban board with a ⤷N chip that morphs to a chevron on hover. Expanded tree shows child rows with status dots, priority badges, and inline drag-and-drop for reparenting. Delete dialog offers recursive subtree deletion. Detach dialog allows unlinking children without deleting them.

### Highlights

- Parent-child task linking: attach children to any task, see them grouped in the board
- Tree view with expand/collapse, inline drag-and-drop reparenting
- Recursive delete: delete a parent and all its descendants in one action
