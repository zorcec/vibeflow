Kanban UI: list view now orders sections todo → in-progress → review → backlog → done; new condensed view mode (compact two-line cards, toggle in the filter bar, persisted per user); lanes fit cards to the visible column height with a "+N more" indicator instead of an unbounded scroll list. Overlay: the add-task dialog gained a collapsible "Advanced" section with tag chips and a priority selector (Critical/High/Medium/Low); both are optional and forwarded to the task creation API.
